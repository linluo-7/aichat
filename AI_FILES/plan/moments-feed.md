# 朋友圈（Moments）设计

> 范围：用户发图文动态；联系人延迟必赞 + 评论；用户可回评，联系人可再回一刀。  
> 前置建议：聊天图片多模态（联系人「看懂」配图）可并行或略先；本计划不阻塞朋友圈表结构。

---

## 1. Goal（验收）

| # | 目标 | 验收标准 |
|---|------|----------|
| G1 | 用户发朋友圈 | 文字必填或图文至少一种；可带 1～9 张图 |
| G2 | 联系人必赞 | 每条用户动态，每个启用中的联系人最终必有一条点赞 |
| G3 | 延迟互动 | 点赞与首评不在发帖当下；在发帖后 **1～3 分钟均匀随机** 执行 |
| G4 | 首评仅一次 | 每个联系人对同一条动态 **最多一条「首评」**（对动态本体） |
| G5 | 楼中楼 | 用户可回复该联系人的首评；之后该联系人可再回复用户（二轮） |
| G6 | 隔离 | 动态/赞/评均按 `user_id` 隔离 |
| G7 | AI 也可发 | 联系人可自发动态（二期可先做开关；一期可只做「用户发 → AI 互动」） |

---

## 2. 已拍板的互动规则（本次）

```
用户发动态 Post
    │
    ├─ 每个联系人：延迟 T ∈ [60s, 180s] 随机
    │     ├─ 必点赞（Like）
    │     └─ 必发一条首评（Comment，parent_id = null，对 Post）
    │           ※ 该联系人对该 Post 首评有且仅有一条
    │
    └─ 用户回复某条联系人首评（Reply，parent_id = 该首评 id）
          └─ 该联系人可再回一条（Reply，挂在同一楼或回用户那条）
                ※ 建议：同一「首评楼」内，联系人再回最多 1 次（避免刷屏）
```

- **不要立刻回**：Worker 调度 `run_after = now + random(60, 180)` 秒。  
- **必点赞**：任务成功路径必须写入 Like；失败可重试，最终一致。  
- **首评配额**：`(post_id, contact_id, kind=root)` 唯一。  
- **用户回评后联系人再回**：可再延迟 1～3 分钟，显得自然。

---

## 3. 数据模型（草案）

### `moment_posts`【朋友圈】动态表
- id, user_id, author_type(`user`/`contact`), contact_id(可空), content, created_at

### `moment_images`【朋友圈】动态图片
- id, post_id, url, sort_order

### `moment_likes`【朋友圈】点赞
- id, post_id, contact_id, created_at  
- UNIQUE(post_id, contact_id)

### `moment_comments`【朋友圈】评论
- id, post_id, author_type, contact_id(可空), user_id(可空), parent_id(可空), content, created_at  
- 首评约束：应用层 + 部分唯一索引（SQLite 可用条件逻辑在服务层保证）

### `moment_jobs`【朋友圈】互动任务
- id, post_id, contact_id, job_type(`like_and_root_comment` / `reply_to_user`), status, run_after, attempts, error…

---

## 4. API（草案）

- `GET /api/moments` 动态流（含赞、评、图）  
- `POST /api/moments` 发帖（multipart 或先发帖再传图）  
- `POST /api/moments/{id}/comments` 用户评论/回复（带 parent_id）  
- `DELETE /api/moments/{id}` 删自己的动态  

联系人侧写赞/评仅服务端 Worker，不开放前端伪造。

---

## 5. 前端

- 入口：会话列表顶栏或「发现」入口进朋友圈  
- 列表：头像、昵称、正文、九宫格图、赞列表、评论串  
- 发帖页：文字 + 选图（复用裁剪/上传）  
- 评论：点某条联系人评论 → 回复  

---

## 6. AI 生成

- 首评 / 再回：带人设 + 记忆块 + 动态正文（+ 后期多模态看图）  
- 语气短、像朋友圈，禁止说「作为 AI」  
- 无 Key / 失败：赞仍尽量写上；评可标失败重试  

---

## 7. 一期范围建议

**做：** 用户发帖、图文、全联系人延迟必赞+首评、用户回评、联系人延迟再回、列表页。  
**可二期：** 联系人主动发动态、动态可见范围、聊天多模态看图后再加强评图质量。
